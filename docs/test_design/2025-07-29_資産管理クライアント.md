# 資産管理クライアント機能 - テスト設計書

## 概要

ネットワーク機器やサーバーの資産情報を管理するREST/GraphQLサーバーから、検索条件に基づいて資産情報を取得するクライアント機能のテスト設計書。

## テスト対象機能

- 資産情報の検索（ID、機種名、ロケーション検索）
- REST API/GraphQL両対応
- Bearer Token認証
- Pydanticによるデータバリデーション
- エラーハンドリング（自動回復、失敗時None返却）

### Error Cases（エラー処理シナリオ）

- [ ] 無効なAssetId（非UUID形式）でのValue Object作成失敗

## テスト実行順序

1. **ドメインレイヤー**: Value Objects → Entities → Repository Interface
2. **インフラストラクチャレイヤー**: REST Client → GraphQL Client
3. **アプリケーションレイヤー**: UseCase
4. **プレゼンテーションレイヤー**: CLI
5. **統合テスト**: 全体フロー

## テスト環境要件

- Python 3.9+
- pytest, pytest-cov
- httpx (REST API テスト用)
- gql (GraphQL テスト用)
- モックサーバー（WireMock等）
- テスト用設定ファイル

## 実装時の注意点

- すべてのテストで日本語コメントを使用
- Pydanticモデルのバリデーションは厳密にテスト
- エラーハンドリングは自動回復 → None返却の順で検証
- DI機能を活用したモックオブジェクトの注入テスト
